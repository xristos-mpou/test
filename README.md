# test

Ένα δοκιμαστικό repository για πειραματισμό με το Git, το GitHub και το Claude Code.

## Περιγραφή

Αυτό το project χρησιμοποιείται ως χώρος δοκιμών. Εδώ μπορείς να:

- δοκιμάσεις εντολές του Git (commit, branch, merge, push)
- πειραματιστείς με νέο κώδικα χωρίς ρίσκο
- δουλέψεις μαζί με τον Claude πάνω σε ένα πραγματικό repo

## Ξεκινώντας

Κάνε clone το repository:

```bash
git clone https://github.com/xristos-mpou/test.git
cd test
```

## Δομή

```
test/
└── README.md
```

## Συνεισφορά

1. Κάνε fork το repository
2. Δημιούργησε ένα νέο branch (`git checkout -b feature/κάτι-νέο`)
3. Κάνε commit τις αλλαγές σου (`git commit -m "Προσθήκη κάτι νέου"`)
4. Κάνε push στο branch (`git push origin feature/κάτι-νέο`)
5. Άνοιξε ένα Pull Request
